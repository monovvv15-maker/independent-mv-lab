# 『えがちゃんへ』MV正式ストーリー台本 V29

状態：**構成原本・保護対象**。2026-11-14 作成者が「これが大切な設計図、台本」と明示し、保存と一括進行を承認。

## 0. 前提
本MVは
- 江頭さんへの手紙
- 「立ち止まってもいい」というメッセージ
- 毎日を生きる誰かへの応援
を軸とする。

## 1. 主題
**「立ち止まることには意味がある」**

描く感情の流れ：
朝が来る → 歩き出す → 誰かの日常が重なる → 立ち止まる → 風に吹かれる → それでもまた少し進む。

## 2. 基本方針
### 主人公
- 特定の一人には固定しすぎない。ただし冒頭の感情の起点は一人の朝。
- 最初は「ひとりの朝」から始め、途中から世界の誰かの日常へ広げる。
- 人物・靴・国・場所が変わってもよいが、それが意図的な群像演出であると伝わるようにする。

### 禁止事項
- 冒頭で知らない女性が突然主役として登場すること
- 同じ素材の使い回しで尺を埋めること
- 歌詞と無関係な「なんとなく綺麗」素材を並べること
- ストーリー抜きの雰囲気だけのMV

### 保護事項
- **出だしは靴を履くところから**
- 足元、手元、風、街、朝の光で感情を作る
- 別の人物は「主役交代」ではなく、日常の共鳴として登場させる
- 過去の写真・動画も再利用候補にするが、全部は採用しない
- 既存素材・原本・V23/V28生成物は上書きしない
- 原曲04および歌詞原本は改変しない

## 3. 全体の物語
1. 朝が始まる
2. 昨日の雨を抱えたまま歩き出す
3. 世界の誰かの朝と重なる
4. 立ち止まることを肯定する
5. 小さな幸せや記憶を感じる
6. またそれぞれの朝へ戻っていく

## 4. 全編ストーリー台本（時刻は仮。原曲の歌唱時刻確定後に編集）

### 第1章｜朝の始まり｜0:00〜0:25
**役割：今日が始まる瞬間を描く。**
- 暗めの室内 → 裸足の足元 → 靴を手に取る → 靴を履く → 紐を結ぶ → 玄関の空気 → 外の気配
- 大きなドラマは起こさない。顔を出しすぎない。主人公を限定せず、感情を伝える。
- 扉から女性が主役として出る既存冒頭は禁止。

### 第2章｜昨日の雨、今日の朝｜0:25〜0:55
**役割：過去の重さを抱えたまま、それでも朝は来る。**
- 玄関を出る／濡れた路面／水たまり／雨上がりの光／朝の街／静かな住宅街／水滴
- 昨日の雨＝苦しさ・迷い・疲れ。暗いだけではなく回復の光を描く。

### 第3章｜歩き出す｜0:55〜1:25
**役割：止まっていた気持ちが少し動く。**
- 白い靴の足元／横断歩道／歩道／曲がり角／通勤通学／住宅街から街へ
- 歩行カットを連発しない。周囲の景色・空気を挟む。
- 「前進」というより日常生活を始める感覚。

### 第4章｜世界の朝が重なる｜1:25〜1:55
**役割：この朝は自分だけのものではない。**
- 別の街で歩く人／窓を開ける人／通勤する人／横断歩道／古い街／世界各地の朝
- ここから意図的に群像へ拡張。各人物の苦しさを否定しない。

### 第5章｜立ち止まること｜1:55〜2:30
**役割：この曲の核心。「立ち止まってもいい」。**
- 風に揺れる花／止まる足元／道端の景色／踏切・待ち時間／空を見上げる／ベンチ／静かな背中
- 派手にしない。頑張れと押しつけず静けさを守る。

### 第6章｜小さな幸せ｜2:30〜3:00
**役割：大事件ではない小さな光に気づく。**
- 朝の光／木漏れ日／誰かとすれ違う／花／静かな住宅街／明るくなった空気
- 感動を押しつけない。「気づき」程度でよい。

### 第7章｜それぞれの明日へ｜3:00〜ラスト（原曲199.872秒）
**役割：またそれぞれの朝へ帰る。**
- 初めの足元の記憶へ戻る／歩き出す／世界の街を短くつなぐ／道の先／空／街の余韻
- 完全解決ではない。今日を生き、また明日へ続いていく静かな終わり。

## 5. 素材の役割
### 主役軸の優先素材
靴を履く／玄関・外へ／歩く靴／雨上がりの道／住宅街の朝。
### 世界観を広げる補助素材
窓／通行人／世界各地の街／古い街／花／電車・踏切／穏やかな終盤の街。

## 6. この作品が伝えたいこと
**「苦しい日があっても、立ち止まってもいい。それでも朝は来るし、世界のどこかで誰かも同じように生きている。」**

完成秘話の核は「江頭さんへの手紙」「立ち止まることの意味」「日々を生きる人への共感」。
歌詞原本の全文照合は別工程で行い、解釈を歌詞の確定事実として上書きしない。

## 7. 制作順序
1. 台本を保護して唯一の演出判断基準にする
2. 過去の写真・動画・映像素材を七章へ再分類
3. 不必要な素材を不採用
4. 不足素材のみ追加調査
5. 作成者の**動画スタイル**を映像演出確定直前に聞いて反映
6. 実素材と原曲の歌詞時刻を精査して全編を構成
7. 動画生成は「動画生成開始」の明示指示後
8. 全編試写を評価し、良い場面を保護・悪い場面のみ修正

**注記：上記各章の秒数は以前の設計時点の仮値であり、歌詞の秒単位同期を保証しない。**
